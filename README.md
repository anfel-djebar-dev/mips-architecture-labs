# MIPS Architecture & Assembly Labs 🖥️⚙️

This repository documents my low-level programming and computer architecture practical works (TPs) in **MIPS Assembly**, undertaken during my second-year in Computer Science / Information Systems (L2-SI).

## 🛠️ Tech Stack & Tools
* **Language:** MIPS Assembly
* **Environment / Simulator:** MARS MIPS / SPIM
* **Focus:** Registers, Memory Management, Arithmetic Operations, and Control Flow.

## 📂 Structure
* `TP1/` - Basic arithmetic, register manipulation, and syscalls.
* `TP2/` - Conditional branches and comparisons (`beq`, `bne`, `slt`).
* `TP3/` - Loops and iterative execution.
* `TP4/` - Advanced branching instructions (`blt`, `bgtz`, `blez`, `bltz`).
